# Vedic IT Labs Website

A responsive business landing website built with HTML5, CSS3, Bootstrap 5.3 and vanilla JavaScript.

## Files
- `index.html` — page structure and Bootstrap components
- `style.css` — custom responsive styling
- `script.js` — contact form validation and interactions
- `assets/vedic-it-labs-logo.jpg` — supplied full official logo
- `assets/vedic-it-labs-icon.png` — transparent logo symbol used in the navbar
- `assets/favicon.png` — browser tab icon

## Run locally
1. Extract this ZIP file.
2. Open the `vedic-it-labs-website` folder in Visual Studio Code.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html` and select **Open with Live Server**.

The page loads Bootstrap and Bootstrap Icons from CDNs, so an internet connection is required for those assets.

## Contact form
The form performs browser-side validation and then opens the visitor's default email application with a pre-filled message addressed to `vedicitlabs@gmail.com`. It does not store or transmit enquiries to a server. For automatic submissions, connect a backend or a trusted form service.

## Before publishing
- Your supplied Vedic IT Labs logo is integrated in the navbar and footer, with a matching browser tab icon.
- Verify the service descriptions and contact details.
- Add your phone number, WhatsApp link and social media URLs if you want them displayed.
- Configure hosting and connect your domain `vedicitlabs.in`.
